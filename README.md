# Netflix Clone

This project is a Netflix landing page clone created for practice while learning frontend web development.

The main purpose of this project was to improve my understanding of:
- HTML
- CSS
- Layout Design
- Positioning
- Flexbox
- UI Cloning
- Basic Responsive Concepts

The design is inspired by the official Netflix homepage.

## Features

- Netflix-inspired UI
- Hero section with background overlay
- Navigation bar
- Movie/series sections
- Clean layout structure
- Hover effects and styling practice

## Tech Stack

- HTML
- CSS

## Project Purpose

This project was built for learning and practice purposes only.

I created this clone to improve my frontend development skills and understand how real-world website layouts are structured.

## Note

This project is not fully responsive because it was created mainly for practice and completed within limited time.

Some sections or layouts may behave differently on smaller screen sizes.
